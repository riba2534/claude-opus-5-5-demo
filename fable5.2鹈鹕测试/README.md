# 豆包单车大作战 · Doubao Bike Blaster

骑着自行车的豆包，对抗满城乱窜的 Bug 和「幻觉」——一个第三人称 3D 单车枪战游戏。
由 Claude Fable 5.2 在 Claude Code 中单会话生成，源码零人工改动。

**在线体验：<https://fable-5-2-doubao.riba2534.cn/>**

整个游戏是一个约 683 KB 的单文件 HTML（线上压缩传输约 201 KB），除页面本身外不发起任何网络请求：
没有图片、没有模型文件、没有音频文件，模型、贴图、音效、配乐全部由代码现场算出来。

> 我需要你去本 Workspace 的另一个 Tab 下调研一下，那个东西用了什么技术，所以这个你要用类似的技术做出来

## 玩法

- 豆包骑车的方向相对镜头：朝哪看、往哪骑；按住「后」是朝镜头骑，可以一边逃一边回头射击
- 四把玩具爆能枪：豆豆冲锋枪、爆米花霰弹枪、深度思考磁轨炮（穿透）、灵感火箭筒（范围爆炸，离爆点近可以火箭跳）
- 车铃冲击波：震退周围敌人并清掉弹幕；深度思考：子弹时间
- 道路跳台、滑板公园起跳台、可以骑上去的平台和货柜；腾空击杀、单车冲撞、连杀都有额外加分
- 六种敌人：成群扑咬的 Bug、会预判射击的乱码兵、盘旋的弹窗无人机、追着你跑的独轮骑手、正面带护盾的防火墙，每 5 波出现 Boss「幻觉之王」（环形弹幕、追踪导弹、可以跳过去的贴地扫射激光、召唤 Bug）
- 每清完一波三选一强化，共 13 种，可叠加
- 昼夜循环：白天、黄昏、夜晚的光照、天空、窗灯和路灯都会变化

## 技术

| 方面 | 做法 |
| --- | --- |
| 渲染底座 | Three.js r186（esbuild 摇树后打包内联），关闭内置抗锯齿，改用渲染目标上的 MSAA |
| 材质 | 标准 PBR 材质 + `onBeforeCompile` 注入：顶点色反照率、自发光、数字溶解、程序化建筑窗户、噪声微观变化、解析式路灯光池 |
| 地面 | 一个着色器按世界坐标画出沥青、裂缝、标线、蓝色自行车道、斑马线、Voronoi 石板广场、草地和滑板公园涂装，凹凸法线来自噪声高度差分 |
| 贴图 | 只有两张，都是运行时生成：一张 256² 的可平铺噪声 DataTexture（fbm / Voronoi 单元 / Voronoi 边距 / 白噪声），一张 Canvas 2D 画的招牌图集（系统字体 + 手绘头像） |
| 模型 | 旋转体、圆角盒、圆环、参数曲面等基础体由代码生成并烘焙合并；豆包的波波头是按发际线参数化的曲面；动态物体走 InstancedMesh |
| 动画 | 分件骨骼 + 两段 IK：腿踩踏板、左手握把、右手持枪指向准星，躯干和头随瞄准方向扭转 |
| 光照 | PCF 软阴影（跟随玩家并按纹素对齐）、PMREM 环境反射随昼夜重新卷积、6 盏点光源池（枪口、爆炸、弹幕） |
| 后处理 | 自建链路：半分辨率 AO + 阴影贴图步进体积光 → 双边模糊 → 相机运动模糊 → 双滤波 Bloom → 镜头光晕 → 自动曝光 → ACES → FXAA |
| 音频 | 纯 Web Audio 合成：音效、卷积混响的脉冲响应、3D 声像、16 步音序器配乐（按战斗强度叠加声部） |
| 物理 | 自写：高度场地形 + 坡道 + 可骑平台，圆 / OBB 碰撞滑移，射线检测 |
| 画质 | 低 / 中 / 高 / 极致四档 + 自动（帧率持续偏低时逐级下调） |
| 输入 | 键鼠（Pointer Lock，失败时降级）、触屏虚拟摇杆、标准手柄 |

豆包的形象依据官方头像的特征（深棕色侧分波波头、大眼睛、黑色圆领 T 恤、浅蓝色背景）自行建模与绘制，没有使用任何官方素材文件。

## 本地构建

```bash
npm install        # three、esbuild
node build.mjs     # 产物输出到 dist/index.html，浏览器直接打开即可
node build.mjs --dev   # 不压缩，便于调试
```

调试用 URL 参数：`?q=low|medium|high|ultra` 指定画质，`?seed=` 世界种子，`?tod=0..1` 固定时刻，
`?start` 跳过菜单，`?auto` 自动驾驶，`?god` 无敌，`?wave=N` 从第 N 波开始，`?spawn=0,1,5` 指定生成的敌人。
控制台里有 `__G`（游戏状态）、`__stats()`、`__sim(秒)`（不渲染快进模拟）、`__errors`。

## 自测

全部在无头 Chromium（SwiftShader 软件渲染）里完成，没有真机和真实显卡上的测试：

- 逐项截图检查了豆包模型、六种敌人、白天 / 黄昏 / 夜晚、主菜单、强化选择、结算界面、手机横屏布局
- 用真实键鼠事件走完「开始 → 骑行 → 开火 → 切枪 → 车铃 → 跳跃 → Esc 暂停 → 继续 → 回主菜单」，用触屏事件验证了摇杆、滑动瞄准、开火、跳跃、换枪、暂停
- 脚本化输入验证单车物理：平地极速 13.2 m/s、冲刺 18.7 m/s；道路跳台巡航起跳最高 1.75 m、冲刺 2.2 m，大起跳台 3.4 m；撞墙、撞货柜、场地边界均不穿透。这一步查出起跳判定依赖子步落点、有时飞不起来的问题并修复
- 自动驾驶 + 无敌快进 13 分钟模拟时间，到第 21 波、击杀 348，无报错，JS 堆约 77 MB 无增长
- 自动驾驶不开无敌跑了 4 局：分别止步第 5、10、10 波和 7.5 分钟时仍存活在第 14 波（这个 bot 不会躲弹幕）
- 运行时切换五档画质、触发窗口缩放，无报错

帧率只在软件渲染下跑过，真实设备上的性能没有实测；手柄输入只做了代码检查，没有接真手柄测试。
